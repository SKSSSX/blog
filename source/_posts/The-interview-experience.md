## 面试公司对应聘者的要求
{% endnote %}

{% blockquote %}
面试我发现一个比较严酷的问题：面试的每家公司都有自己的特点，有些公司注重页面优化，注重前面的东西，node服务的东西很少甚至没有，跟自己的研究方向有些偏差，基本上也是对不上口味。
{% endblockquote %}

{% blockquote %}
有些公司正好相反，侧重后台逻辑，不注重前台页面优化，随便写就行。
{% endblockquote %}

## 面试公司对人的价值导向
{% endnote %}

{% blockquote %}
他们都是招符合自己口味的，其实这些都是程序员的固定思维，觉得面试者不符合自己的预期就不会要，而从不会注重面试者灵活运用知识，热爱前端这些方面。
{% endblockquote %}

{% blockquote %}
只要不合口味，或者技术见解不一致，就不要。
{% endblockquote %}

## 举个栗子
{% endnote %}

{% blockquote %}
比如我在当前公司天天干的什么工作，跟面试那家做的不是很契合，人家准不会满意，就连技术见解不一致也会pass的。
{% endblockquote %}

## 个人观点
{% endnote %}

{% blockquote %}
我要说程序员过于偏执，不能求同存异吧？即使天天看面试题，也不能打中面试公司的要害，这就是为了迎合面试公司，才去做这些事，没办法，为了生存。
{% endblockquote %}
