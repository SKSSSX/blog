## 用高标准来严格要求自己
{% endnote %}

{% blockquote %}
#1、
对于工作，别人靠运气，人脉，而我，想靠实力，即使有好的运气，好的人脉，没有实力也是万万不行的
{% endblockquote %}

{% blockquote %}
#2、
“怕” -- 前端初学者犯的最大的错误并不是代码写的不好，而是从心里就开始怕了，怕去尝试新技术，怕领导部署的任务完不成，进而用更多的插件来加速开发，到最后自己并没有学到什么，只是单纯的一个“码农”。
{% endblockquote %}

{% blockquote %}
#3、
对于代码级别的问题，编程思想  和 代码基础 缺一不可， 有了编程思想才能更灵活的运用已有的语法结构创造出自己需要的东西。编程思想极为重要
{% endblockquote %}

{% blockquote %}
#4、
对于前端这门技术的无限延伸和学习，一方面要追求“新”，一方面要追求对自己已学知识的把握程度上。
{% endblockquote %}

{% blockquote %}
#5、
开发属于自己的UI组件，js工具函数，乃至框架的编写
{% endblockquote %}

## 找到自己的定位
{% endnote %}

{% blockquote %}
对于一个入职场7年的人，其实我在乎的不是薪水和职位，最在乎的其实是两件事：
1.自己到底是不是在干一件发自内心想做，而且真的能给社会创造价值的事情；
2.自己是不是和牛人一起工作，能不能在岗位上跟牛人学本事。
{% endblockquote %}

{% blockquote %}
人所处的环境和领域不同，只有找到适合自己发展的空间，才能发挥最大的价值，程序员也一样。
想找一家更互联网的公司
选对方向，跟对项目，有足够的学习机会，以及有较大概率能够做出成就。
{% endblockquote %}

## 一个优秀程序员应具备的职业素养
{% endnote %}

{% blockquote %}
1. 兴趣：兴趣为导向去研究代码、框架，远比把这个职业当成“混口饭吃”的工具强得多。
{% endblockquote %}

{% blockquote %}
2. 学习能力：往往每个人对做技术这个事上领悟能力不同，有些是从别的行业转过来的，但是最主要的是具备编程思想。
{% endblockquote %}

{% blockquote %}
3. 代码：对于代码语法来讲，会的都差不多，但是如何组织代码，让其维护起来更方便，良好的代码规范；运用大家熟知的设计模式来设计代码结构，写代码的时间很短，思考时间占很多时间。
{% endblockquote %}

{% blockquote %}
4. 解决方案：例如：有人用sass、less 等解决css整体的样式结构问题，每人分配一小块单独的样式，最终合并成一个sass，再转成css；还有一个解决方案是：把css样式写成单独的模块写入到页面中去，vue 就可以给每个页面的css标记单独的作用域，使页面和页面之间不冲突。
{% endblockquote %}

{% blockquote %}
5. 细致度：我自己本身就是一个细致的人，而我的职业刚好也是需要这样的性格，一张设计图，细到一个图标，因为我们是展示给用户看的，用户体验好不好也是我们努力的方向，代码的健壮性也需要诸多考量，要是不细致，难以做好前端。
{% endblockquote %}

{% blockquote %}
6. 代码库、知识库：在工作之余，最好自己能自己做一些轮子，要自己分析能力进一步提高，与诸多同行交流；现在我们公司总算建立起了这个兴趣小组，代码库；为以后新的项目打好知识基础和项目脚手架等，不至于措手不及。
{% endblockquote %}

{% blockquote %}
7.  本着以上的原则，我在这个行业上，一天比一天是个进步，自己遇到好的技术，现在依然是满心欢喜。
{% endblockquote %}
