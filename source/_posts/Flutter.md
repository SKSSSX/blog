## 引语
{% blockquote %}
Flutter 是 Google 研发的 移动 UI 框架，可以快速在iOS和Android上构建高质量的原生用户界面。
{% endblockquote %}

## Dart
{% blockquote %}
Dart 是 Flutter 的开发语言， 如同 IOS开发用 swift 一样, 
{% endblockquote %}

## Flutter SDK
{% blockquote %}
### Flutter SDK里面有什么？
 - 深度优化了的、移动优先的2D渲染引擎
 - 现代、响应式框架
 - 丰富的Android和iOS套件
 - 单元和集成测试的API
 - 连接到系统和第三方SDK的Interop和插件API
 - 无头的测试运行器，用于在Windows、Linux和Mac上运行测试
 - 用于创建、构建、测试和编译应用程序的命令行工具
{% endblockquote %}

## 开发Flutter的环境配置

{% blockquote %}
1、JDK 需要配置环境变量
    JAVA_HOME=D:\Environment\jdk-14.0.2
    %JAVA_HOME%\bin
    %JAVA_HOME%\jre\bin
    $ java --version
{% endblockquote %}

{% blockquote %}
2、Gradle 依赖于 JDK，同样需要配置环境变量
   GRADLE_HOME=D:\Environment\gradle\bin
   $ gradle -v
{% endblockquote %}

{% blockquote %}
3、Android SDK
   需要配置三个环境变量
   ANDROID_HOME=D:\Environment\Android\android-sdk

   %ANDROID_HOME%\emulator
   %ANDROID_HOME%\platform-tools
   %ANDROID_HOME%\tools
{% endblockquote %}

{% blockquote %}
4、Flutter SDK
   需要配置环境变量D:\Environment\flutter\bin
   $ flutter doctor
{% endblockquote %}

{% blockquote %}
5、Android Studio 中配置
   - 打开我们的studio ，分别安装插件
    •	dart
    •	flutter
   - 安装完成 重启软件 后 配置SDK 路径
   Dart SDK 配置
   Flutter SDK配置
{% endblockquote %}
